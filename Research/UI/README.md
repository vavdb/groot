## Copyright / IP position

All safe by construction:

- **Code & layout**: every mockup hand-authored HTML/CSS in this repo; nothing copied from any
  app or site. Style *inspiration* (StrongLifts's one-tap circles as interaction concept,
  vincability/Vindicator as the owner's own prior work) is not copying — and Vindicator is
  the owner's own IP anyway.
- **Interaction patterns** (set circles, rest timer, plate calculator, auto progression): unprotectable
  functional ideas used across the whole category (StrongLifts, Strong, Hevy, PTC). No copied
  artwork, icons, screenshots, sounds, or copy.
- **Fonts**: Google Fonts (Fraunces, Public Sans, etc.) — SIL Open Font License, commercial use fine.
  If later self-hosted, keep the OFL notices.
- **Exercise media**: `vavdb/exercises-dataset` fork — MIT (attribution: keep LICENSE + NOTICE.md).
  Fallback stills: `yuhonas/free-exercise-db` — public domain (Unlicense).
- **Program names**: "GZCLP", "nSuns 531", "GreySkull LP", "StrongLifts 5x5" are references to
  training methodologies. Methodologies themselves aren't copyrightable; but the *names* can carry
  trademark weight ("StrongLifts" certainly, "GreySkull LP" is trademarked by its author). Ship
  generic descriptors or user-created program names; do not market Groot as "a StrongLifts app".

## ⚠ The one real risk: the name "Groot"

The name is a plain Dutch word. "Groot" as a
plain Dutch word for a Dutch-made fitness app in a different trademark class is defensible, BUT:

1. **Never** use a humanoid tree *character*/mascot — that walks straight into the a character design.
   The tree-*rings* identity (abstract growth rings, botanical, no face, no limbs) is exactly the
   safe lane. The rejected pastel direction's "sprout mascot" idea dies here — documented as rejected.
2. Avoid character copy ("I am Groot", talking-tree jokes) anywhere in the product or store listing.
3. If the app ever goes commercial/store-wide, do a proper trademark search (Benelux/EUIPO class 9/41/42)
   or keep "Groot" as working title and rename at launch.
